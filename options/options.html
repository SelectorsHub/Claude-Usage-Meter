Session (5-hour) thresholds

Notifications for the rolling 5-hour message window.

Weekly thresholds

Applied independently to every weekly quota your account reports — the all-models weekly total and each per-model one (Fable, Opus, Sonnet, Haiku). Crossing a threshold fires once, then re-arms when that quota resets. If usage passes several thresholds between polls, only the highest one fires.

Polling & notifications

Saved.

How it works. The extension polls GET /api/organizations/{id}/usage using your existing browser session cookie. The weekly card auto-labels with whichever Claude model you're actively using on claude.ai.

These endpoints are undocumented. If Anthropic changes them, an update may be needed.
