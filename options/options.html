Claude Usage Meter

Configure notifications and chat behaviour.

Language

Pick a language, or let it follow the language you use on Claude.ai.

Session (5-hour) thresholds

Notifications for the rolling 5-hour message window.

Weekly thresholds

Applied to whichever weekly quota you're using (Sonnet, Opus, Haiku). Each fires once per cycle when crossed.

Polling & notifications

Extra usage

For accounts with extra usage turned on (Team, Enterprise, Max): how much you’ve spent past your plan limits this month, against your monthly limit. Shows only when Claude reports it for your account.

Chat box

Adds a Projects button beside Chat / Cowork so you can jump straight into any project instead of walking the plus menu.

Sidebar

Adds a search box above “Chats and tasks” that filters every chat on your account by title as you type. There’s also a button to read the messages themselves — that one reads your recent chats one by one, so it only ever runs when you press it.

Saved.

How it works. The extension polls GET /api/organizations/{id}/usage using your existing browser session cookie. The weekly card auto-labels with whichever Claude model you're actively using on claude.ai.

These endpoints are undocumented. If Anthropic changes them, an update may be needed.
